## New Age refresh

Uses the official Start Bootstrap New Age distribution CSS (including Bootstrap layout), customized in assets/new-age/brand.css. MIT license included alongside the vendored CSS. No build or third-party runtime is required. Serve this directory with python3 -m http.server. Existing support/privacy/terms URLs and wording are retained; original CSS is retained for history but no longer loaded. App Store destinations come from verified live Apple listings. Hosting configuration is unchanged.
